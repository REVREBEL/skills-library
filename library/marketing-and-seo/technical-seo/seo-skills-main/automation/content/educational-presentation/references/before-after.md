# Before & After Slide Transformations

## Introduction

Ce document présente des exemples concrets de transformation de slides "Death by PowerPoint" en présentations cognitively optimisées.

---

## Principes de Transformation : Récapitulatif

### Transformation Type 1 : "De-textualization"
**Action** : Mur de texte → Visuels + Keywords + Notes
**Gain** : -70% charge cognitive

### Transformation Type 2 : "Segmentation"
**Action** : 1 slide surchargée → 3-5 slides focalisées
**Gain** : +90% compréhension

### Transformation Type 3 : "Progressive Disclosure"
**Action** : Tout visible → Révélation étape par étape
**Gain** : +80% attention

### Transformation Type 4 : "Visual Hierarchy"
**Action** : Centré/plat → Aligné + Contraste fort
**Gain** : +60% vitesse de scan

### Transformation Type 5 : "Data Simplification"
**Action** : 8 variables → 1-3 variables clés
**Gain** : +75% rétention du message

### Transformation Type 6 : "Active Learning"
**Action** : Contenu seul → Contenu + Pratique + Feedback
**Gain** : +150% rétention long terme

## Métrique de Succès : Score CRAP-Mayer

Pour chaque slide, évaluez sur 12 points :

**Mayer (6 pts)** :
- [ ] Cohérence (pas de superflu)
- [ ] Redondance évitée (pas texte + narration)
- [ ] Multimédia (mots ET images)
- [ ] Contiguïté spatiale (labels près des visuels)
- [ ] Signalisation (élément important mis en évidence)
- [ ] Segmentation (1 idée par slide)

**CRAP (4 pts)** :
- [ ] Contraste fort (hiérarchie claire)
- [ ] Répétition (design cohérent)
- [ ] Alignement (grille invisible)
- [ ] Proximité (éléments liés groupés)

**Accessibilité (2 pts)** :
- [ ] Contraste 4.5:1 minimum
- [ ] Police 24pt minimum

**Score idéal : 12/12**
**Score acceptable : 10/12**
**Score à retravailler : <10/12**

## Conclusion

La transformation de slides ne consiste pas à "faire joli" mais à **faciliter l'apprentissage** en :
1. Réduisant la charge cognitive extrinsèque
2. Gérant la charge intrinsèque par chunking
3. Maximisant la charge germanique (apprentissage réel)

**Chaque décision de design est une décision pédagogique.**
